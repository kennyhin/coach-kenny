    Save straight to GitHub

    Paste a GitHub personal access token that can read and write this repo. Save commits your edits; GitHub Pages updates in about a minute.

    The token is stored in this browser only (localStorage) and is only sent to api.github.com. Don't set it up on a shared or student machine — use Export there instead. If Save suddenly fails with 401, the token expired: Forget it and paste a new one.

    Recommended: github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Resource owner kennyhin → only coach-kenny → Permissions → Contents: Read and write. Or a classic token with the repo scope. Connect verifies the token before storing it.
