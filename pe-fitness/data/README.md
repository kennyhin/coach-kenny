# PE leaderboard data

`mile-leaderboard.json` on this branch is **sample data** — fictional first names and last initials only.

This repository is public. Do not commit real student names, times, or class lists here, not even on a draft branch. Live class scores should come from the private Roll Call feed or from a separate commit that Kenny reviews and approves.

The loader reads `mile-leaderboard.json`. A local, out-of-repo file can be used to render real-data screenshots.
