# PE leaderboard data

`mile-leaderboard.json` on this branch is **sample data** — fictional first names and last initials only — for the one-mile run.

This repository is public. Do not commit real student names, times, or class lists here, not even on a draft branch. Live class scores should come from the private Roll Call feed or from a separate commit that Kenny reviews and approves.

The leaderboards page is organized by the official Presidential Fitness categories (Cardiorespiratory Fitness, Upper Body Strength, and Core & Abdominal Strength). Each event uses age groups 8–11. The committed sample file covers the one-mile run only; the other five events show an empty "Results coming after testing" state, not made-up scores.

The loader reads `mile-leaderboard.json`. A local, out-of-repo file can be used to render real-data screenshots of the mile board.
